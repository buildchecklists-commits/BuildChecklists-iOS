# Туры обучения DEMO

Статус: **продуктовая функция DEMO** (не прототип). Все 7 туров реализованы. Обучение доступно только при `store.isDemoMode`, никогда не показывается в зарегистрированном профиле и **не стартует само** при входе в DEMO — только по кнопке «Обучение». Старые `DemoCoachNote` в DEMO **всегда скрыты** (`AppStore.showsDemoCoach` → `false`), чтобы не дублировать тур. StoreKit, подписка, онбординг, история замечаний, уведомления и `ProjectQuickActions` не менялись.

Аргумент запуска `-DemoTrainingPrototype` больше не нужен. Только диагностика (DEBUG): `-DemoTrainingGallery` (галерея chrome), `DemoTrainingCaptureDriver` (`-DemoTrainingAutoEnterDemo`, `-DemoTrainingShot=…`, `-DemoTrainingTour=<тур> -DemoTrainingStep=<n>`). Обычный запуск от них не зависит.

## Аудит экранов (факты UI)

| Раздел | Где в приложении | Что реально есть |
| --- | --- | --- |
| Проекты | `ProjectsListView`, `ProjectDashboardView` | Фильтры/сортировка, календарь задач, калькулятор, карточки с прогрессом, дашборд: сводка, замечания, задачи, быстрые действия, «Ход строительства» |
| Сроки | `PlanProjectsListView` → `ProjectPlanView` | Список объектов по срокам, плановые/фактические даты этапов, просрочки |
| Бюджет | `BudgetProjectsListView` → `BudgetProjectView` | Карточки с суммой, сводка бюджета, план/факт по этапам, операции |
| Фото | `GlobalPhotosView` → `FullScreenPhotoGallery` | Фильтр по источнику, сортировка/фильтр, группы по давности, пустое состояние, существующий полноэкранный просмотр |
| Профиль | `ProfilePlaceholderView` | Аккаунт и тариф, тема оформления; «Создать профиль» — в демо-блоке на «Проектах» |
| Календарь задач | баннер → `TasksCenterView` | Неделя/месяц, счётчики, список или пустое состояние, «+» → форма задачи |
| Калькулятор | кнопка → `CalculatorHomeView` | Список расчётов, `ConcreteCalculatorView`: параметры и блок результата |

Не обещать: облачную синхронизацию, покупку из тура, создание реальных PDF, системный запрос разрешений из шага обучения, автоопределение этапа по фото, напоминания по датам, «работу без ограничений» только из‑за профиля (доступ зависит от тарифа), что «все данные DEMO не сохраняются» — вместо этого: «После перезапуска учебного проекта нет в списке. Демо можно открыть заново».

## Правила безопасности «Далее»

- Только навигация: вкладка, push существующего экрана, sheet с существующим экраном.
- Не создавать задачи, расходы, статусы чек-листа, PDF, покупки, не запрашивать разрешения, не менять тему, не открывать выбор фото / системный альбом.
- Обзорные шаги: не просить нажать или ввести то, что оверлей блокирует; объяснять назначение и вести кнопкой «Далее».
- Форма «Новая задача» открывается пустой; задача создаётся только кнопкой «Сохранить» пользователем. Закрытие тура закрывает форму без сохранения.
- Калькулятор в туре: изолированный учебный пример на экземпляре, открытом туром (`ConcreteCalculatorView(trainingExample: true)` → 10×6×0,2 м → 12 м³ / 12,6 м³ с 5%). Обычный запуск калькулятора, ранее введённые значения, формулы и данные проектов не меняются.
- Фото: при наличии снимка — открыть существующий `FullScreenPhotoGallery`; при пустом списке — короткий маршрут без просмотра. Счётчик шагов соответствует выбранному маршруту. Снимки и разрешения не меняются.
- Повтор тура **не сбрасывает** сессионные данные DEMO.
- Закрытие тура, **ручная** смена вкладки, выход из DEMO снимают подсветку, закрывают sheet-ы тура, снимают все `request*` флаги и отменяют отложенную навигацию. Свайп-закрытие sheet-а тура завершает тур.
- Программная навигация тура (arrive) не завершает тур (`expectedTabChange`).

## Архитектура

- `DemoTrainingController` — состояние тура + `@Published` флаги навигации: `requestOpenDemoDashboard`, `requestOpenDemoPlan`, `requestOpenDemoBudget`, `requestOpenTasksCenter`, `requestPresentCalculator`, `requestPresentTaskForm`, `requestPushConcreteCalculator`, `requestPresentPhotoViewer`, `requestExpandBudgetPlan`. Все сбрасываются в `endTour`.
- `DemoTrainingArriveAction` → `DemoTrainingRoute` (декларативная цель: вкладка + push/sheet). Следовательно, «Далее» и «Назад» идемпотентны.
- `DemoTrainingRouter` (в `DemoTrainingHost`) приводит приложение к цели поэтапно: закрыть sheet-ы → pop / смена вкладки → push → открыть sheet-ы, с паузами под анимации и проверкой эпохи.
- Push-назначения: корневой стек (дашборд, календарь задач) — `demoTrainingNavigation()`; вкладка «Сроки» — `demoTrainingPlanTabNavigation()`; «Бюджет» — `demoTrainingBudgetTabNavigation()`; sheet калькулятора — `demoTrainingCalculatorNavigation()` (push бетона с `trainingExample: true`).
- Sheet-ы выше корневого overlay, поэтому шаги в sheet-ах (`surface: .sheet`) рисуют chrome внутри sheet-а (`demoTrainingSheetOverlay()`); корневой overlay на этих шагах скрыт.
- Мосты `@State` ↔ флаги: форма задачи (`TasksCenterView`), калькулятор (`ProjectsListView`), просмотр фото (`GlobalPhotosView`), раскрытие «План / факт» (`BudgetProjectView`).
- Маршрут фото: `DemoTrainingPhotosProbe` + `photosTourHasPhotos` фиксируются при `startTour(.photos)`.
- Якоря `.demoTrainingAnchor(...)` сообщают рамку контроллеру только пока тур запущен.
- Таб-бар остаётся нажимаемым на шагах «корень вкладки»: блокирующий слой не накрывает нижнюю полосу, нажатие на другую вкладку завершает тур.

## Сценарии

### 1. Проекты (5)
1. Список объектов — фильтры (`projectsListHeader`).
2. Карточка учебного проекта (`projectsDemoCard`) — «Далее» откроет объект.
3. Сводка на дашборде (`projectsDashboardProgress`).
4. «Ход строительства» — назначение этапов (`projectsDashboardStages`).
5. «Быстрые действия» (`projectsQuickActions`).

### 2. Сроки (5)
1. Вкладка и фильтры (`deadlinesListHeader`).
2. Даты на карточке (`deadlinesDemoCard`) — «Далее» откроет план.
3. Экран плана — шапка проекта (`deadlinesPlanHeader`, `openDemoProjectPlan`).
4. «Этапы и сроки» — плановые даты, «Завершить», причина просрочки (`deadlinesTimelineIntro`).
5. План/факт по этапу (`deadlinesFirstStage`).

### 3. Бюджет (5)
1. Вкладка (`budgetListHeader`).
2. Карточка с деньгами (`budgetDemoCard`) — «Далее» откроет подробности.
3. Сводка бюджета (`budgetDetailHeader`, `openDemoBudgetDetail`).
4. План и факт по этапам, блок раскрывается (`budgetPlanFact`, `expandBudgetPlanFact`).
5. Операции (`budgetOperations`). Расходы не добавляются.

### 4. Фото (3 или 4)
1. Источник «Все / Проект / Чек-листы» (`photosSourceFilter`).
2. Сортировка и фильтр (`photosFilterSort`).
3. Первая группа по времени **или** пустое состояние (`photosFirstGroupOrEmpty`).
4. **Только если есть снимок:** существующий просмотр (`photosViewer`, `presentPhotoViewer`, sheet). Назад / крестик / завершение закрывают просмотр и тур корректно. Без снимков шаг 4 отсутствует (счётчик «3 из 3»).

### 5. Профиль (3)
1. Аккаунт и тариф в DEMO (`profileAccountDemo`) — текст про перезапуск учебного проекта, не «данные не сохраняются».
2. Тема оформления (`profileTheme`) — тема не переключается.
3. «Создать профиль» (`profileCreateProfileHint`) — сохранение данных; доступ зависит от тарифа.

### 6. Календарь задач (5)
1. Баннер на «Проектах» (`taskCalendarEntryBanner`).
2. Календарь: неделя/месяц (`taskCalendarHeader`, `openTasksCenter`).
3. Счётчики и список / пустое состояние (`taskCalendarListOrEmpty`).
4. Кнопка «+» (`taskCalendarAddButton`).
5. Пустая форма «Новая задача» в sheet-е (`taskCalendarFormDescription`, `presentNewTaskForm`) — обзор полей, без ввода через оверлей, без сохранения.

### 7. Калькулятор (4)
1. Кнопка «Калькулятор» (`calculatorEntryButton`).
2. Список расчётов (`calculatorHomeList`, `presentCalculatorSheet`).
3. Учебный пример параметров бетона (`calculatorConcreteParams`, `pushConcreteCalculator`) — 10 / 6 / 0,2 м, запас 5%.
4. Результат примера (`calculatorConcreteResult`) — 12 м³ / 12,6 м³. Экземпляр только тура.

## Вход

Кнопка «Обучение» (капсула) на всех 5 вкладках, только в DEMO:
- Проекты — отдельная строка над инструментами списка (не сжимает сортировку/калькулятор).
- Сроки / Бюджет / Фото — справа в строке заголовка вкладки.
- Профиль — отдельная строка вверху прокрутки.

Меню «Что хотите освоить?» — «Разделы» и «Инструменты»; бейджей «Скоро» нет.

## UI карточки (без изменений дизайна в этом проходе)

- Зоны нажатия крестика и «Назад»/«Далее» ≥ 44×44 pt.
- Крупный Dynamic Type / accessibility: карточка почти на всю ширину; счётчик отдельно; кнопки вертикально; тело объяснения прокручивается при нехватке высоты.
- Затемнение с «дыркой»; оверлей не раздвигает список; pan по затемнению листает нижний scroll.
- Reduce Motion: без scale/переездов карточки.

## Проверки

Обычный продуктовый запуск: схема `BuildChecklists` **без** аргументов `-DemoTraining*`. Обучение открывается только кнопкой «Обучение» в DEMO.

Диагностика (DEBUG, не для приёмки жестов): `-DemoTrainingAutoEnterDemo`, `-DemoTrainingTour=<…> -DemoTrainingStep=<n>`, `-DemoTrainingShot=<…>`, `-DemoTrainingGallery`. **CaptureDriver ≠ ручная проверка Next/Back.**

### Подтверждено пользователем (жесты, обычный DEMO)

- Тур «Фото» проходит без зависания на «Листайте выше» (в т.ч. после фикса видимости / закреплённых фильтров).
- Остальные сценарии, которые пользователь успел проверить вручную, работают.

### CaptureDriver / сборка (не жесты)

| Пункт | Статус |
| --- | --- |
| Сборка текущего Swift | OK (`xcodebuild`) |
| Кадры CaptureDriver (справочно) | calc result, task form, photos viewer / step1–3 — в `Docs/demo-training-shots/live/` (в git не входят) |
| Тексты, учебный калькулятор 10×6×0,2, маршрут фото + viewer | в коде |

### Осталось непроверенным или вне объёма приёмки

- Пустой список фото (маршрут «3 из 3») — если не гоняли отдельно.
- Зарегистрированный профиль без кнопки «Обучение» — если не гоняли отдельно.
- SE + Dynamic Type XXXL + тёмная тема на всех семи турах — выборочно / по возможности.
- Полный матричный прогон каждого тура на всех размерах устройств.

### Краткий ручной чеклист (без диагностических аргументов)

1. DEMO → «Обучение» на вкладках → меню без «Скоро».
2. Фото со снимками: Далее → просмотр → Назад / крестик / Завершить.
3. Калькулятор: учебный пример 12 / 12,6 → вне тура поля пустые.
4. Календарь: форма → Назад → повтор → крестик без сохранения.
5. Повтор тура; ручная смена вкладки завершает тур; нет запоздалого sheet после выхода.
