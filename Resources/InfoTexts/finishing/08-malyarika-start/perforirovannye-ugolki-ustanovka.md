# Установка перфорированных уголков

## Что проверяем
- Прямолинейность наружных углов.
- Полное заполнение раствором под уголок.
- Жёсткость фиксации.
- Привязку к дальнейшей геометрии помещения.

## Контроль
- Выставляем уголок по лазеру.
- Заполняем пространство под ним шпаклевкой без пустот.
- Проверяем ровность по всей высоте.
- Даём подсохнуть перед основным слоем.

## Типичные ошибки
❌ Уголок «гуляет».  
❌ Пустоты под уголком.  
❌ Неровная линия по высоте.  
❌ Крепят только на пару точек шпаклёвки.

## Быстрый чек-лист
✅ Уголок ровный.  
✅ Пустот нет.  
✅ Линия идеальная.  
✅ Угол готов под финишный слой.
