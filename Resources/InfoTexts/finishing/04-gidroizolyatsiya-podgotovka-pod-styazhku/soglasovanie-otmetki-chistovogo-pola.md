# Согласование отметки чистового пола

## Что проверяем
- Высоту чистового пола по всему объекту.
- Переходы между разными покрытиями.
- Уровень в санузлах и душевых.
- Совместимость с толщиной финишного пола.

## Контроль
- Строим единую отметку чистового пола лазером.
- Проверяем зоны порогов и переходов.
- Сверяем уровни с толщиной плитки, ламината, паркета.
- Фиксируем решение с заказчиком.

## Типичные ошибки
❌ Делают отметку «на глаз».  
❌ Не учитывают толщину финишного покрытия.  
❌ Не согласовывают уровень — потом жалобы «полы пляшут».  
❌ Разный уровень между комнатами без необходимости.

## Быстрый чек-лист
✅ Единая отметка по всему дому.  
✅ Переходы между покрытиями выровнены.  
✅ Уровни санузлов учтены.  
✅ Решение согласовано с заказчиком.
