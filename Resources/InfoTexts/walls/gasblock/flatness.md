# Плоскость и перепады

## Что проверяем
- Перепады между соседними блоками.
- Общая плоскость стены.

## Контроль
- Локально: ≤ 3 мм; по плоскости: правило 2 м — просвет ≤ 5 мм.
- Подравнивание рубанком/тёркой сразу после укладки.

## Типичные ошибки
❌ «Лестница» из блоков, не подрезают кромки.  
❌ Не контролируют плоскость по ходу кладки.

## Быстрый чек-лист
✅ Просвет по правилу ≤ 5 мм.  
✅ Перепады между блоками ≤ 3 мм.  
✅ Тёрка/рубанок реально используются.
