# Первый ряд газобетона

## Что проверяем
- Укладка первого ряда на цементно-песчаный раствор (ЦПР).
- Выравнивание в уровень по всему периметру.

## Контроль
- Толщина постели ЦПР достаточна для выравнивания.
- Контроль лазером/правилом через каждые 1–2 метра.

## Типичные ошибки
❌ «Клей вместо ЦПР» в первом ряду.  
❌ Не выведен общий уровень — накапливаются ошибки.

## Быстрый чек-лист
✅ Первый ряд на ЦПР.  
✅ Перепад между углами ≤ 3 мм.  
✅ Фото первого ряда с уровнем/лазером.
