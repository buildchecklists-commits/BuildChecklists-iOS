# Основание и гидроизоляция

## Что проверяем
- Ровность основания/цоколя: отклонение ≤ 3 мм на 2 м правилом, диагонали сходятся.
- Горизонтальная гидроизоляция первого ряда (рулон/мастика) — сплошная, без разрывов и складок по всему периметру.
- Отсечка капиллярной влаги в уровне первого ряда, совмещена с проектной отметкой нуля.
- Основание чистое, без пыли/раствора/высолов, подготовлен контакт для раствора.

## Контроль
- Первый ряд начинаем с маячных кирпичей, шнур-причалка, постоянный контроль уровнем/правилом.
- Проверка перепада уровня через каждые 2–3 м, корректировка толщиной постели.
- Гидроизоляция заведена на угол без разрывов; нахлёст и примыкания по ТУ.

## Типичные ошибки
❌ «Ступенька» основания — уводит фасад и швы.  
❌ Порваны/непроклеены стыки гидроизоляции.  
❌ Загрязнённое основание — слабая адгезия.  
❌ Нулевая отметка «гуляет», не совпадает с проектом.

## Быстрый чек-лист
✅ Ровность основания в допуске, диагонали сходятся.  
✅ Гидроизоляция сплошная, с правильным нахлёстом.  
✅ Первый ряд размечен (маячные), шнур-причалка натянута.  
✅ Основание очищено, рабочее место подготовлено.
