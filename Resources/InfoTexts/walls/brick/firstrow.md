# Первый ряд

## Что проверяем
- Раствор/клей по ТУ, выравнивание по уровню/лазеру.
- Контроль перепада: ≤ 3 мм между кирпичами.
- Заполнение постели без пустот.

## Контроль
- Шнур-причалка, маячные кирпичи, проверка каждой ставкой уровня.

## Типичные ошибки
❌ Пустоты под кирпичом.  
❌ Перепады > 3 мм.  
❌ Сбита плоскость с нулевого ряда.

## Быстрый чек-лист
✅ Постель заполнена.  
✅ Перепад ≤ 3 мм.  
✅ Ряд выведен по уровню.
