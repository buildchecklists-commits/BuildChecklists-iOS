# Кладка: перевязка и швы

## Что проверяем
- Перевязка рядов: **не менее 1/2 кирпича** (минимум 1/4 допускается только в узлах/примыканиях по проекту).
- Вертикальные швы: **заполнены раствором** по всей толщине, без пустот.
- Толщина швов: горизонтальные **10–12 мм**, вертикальные **8–12 мм**.
- Совпадения вертикальных швов **не допускаются**.

## Контроль
- Порядовка/шнур-причалка на каждом ряду.
- Снятие излишков раствора **до** схватывания, чистый фасад.
- Проверка перевязки в углах/пересечениях через 2–3 ряда.

## Типичные ошибки
❌ Пустошовка (незаполненные вертикальные швы).  
❌ Совпадение вертикальных швов, «кресты».  
❌ «Гуляющая» толщина швов, нарушение рисунка кладки.  
❌ Выдавленный на лицо раствор, загрязнение фасада.

## Быстрый чек-лист
✅ Смещение швов ≥ 1/2 кирпича (узлы — по проекту).  
✅ Вертикальные швы полностью заполнены.  
✅ Горизонтальные 10–12 мм, вертикальные 8–12 мм.  
✅ Фасад чистый, без потёков.
