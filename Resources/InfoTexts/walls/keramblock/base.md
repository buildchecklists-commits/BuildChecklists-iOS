# Основание под кладку керамоблока

## Что проверяем
- Ровность и горизонталь цоколя по нивелиру.
- Наличие гидроизоляции без разрывов.
- Чистое основание без пыли и мусора.

## Контроль
- Перепад по высоте ≤ 5 мм на всё здание.
- Гидроизоляция выведена на 50 мм за край первого ряда.

## Типичные ошибки
❌ Гидроизоляция с пропусками.  
❌ Основание пыльное, не очищено.  
❌ Первый ряд уложен на сухое основание.

## Быстрый чек-лист
✅ Цоколь ровный, сухой.  
✅ Гидроизоляция уложена сплошным слоем.  
✅ Кладка ведётся с раствором по ТУ.
