# Основание и гидроизоляция первого ряда

## Что проверяем
- Ровность цоколя/плиты: отклонение ≤ 3 мм на 2 м, диагонали сходятся.
- Сплошная гидроизоляция первого ряда без разрывов.
- Отсечка капиллярной влаги по периметру несущих стен.

## Контроль
- Первый ряд — на растворе с выравниванием в уровень.
- Проверка правилом/лазером, фотофиксация.

## Типичные ошибки
❌ «Ступенька» основания — уводит кладку.  
❌ Разрывы/нахлёсты изоляции.  
❌ Нулевой ряд без защиты.

## Быстрый чек-лист
✅ Основание ровное.  
✅ Гидроизоляция сплошная.  
✅ Маски отбиты, шнур натянут.
