# Первый ряд

## Что проверяем
- Выставление по уровню/лазеру, перепад между блоками ≤ 3 мм.
- Верный стартовый формат кладки (углы/доборы).

## Контроль
- Раствор по ТУ, компенсация неровностей основания.
- Проверка каждые 2–3 блока, фотофиксация.

## Типичные ошибки
❌ Перепад по ряду > 3 мм.  
❌ Неверный старт углов, срыв перевязки.  
❌ Пустоты под блоком.

## Быстрый чек-лист
✅ Ряд в уровне.  
✅ Перепад ≤ 3 мм.  
✅ Углы выставлены.
