# Подбор оконного профиля и комплектующих

## Что проверяем
- Класс профиля: A (предпочтительно).
- Армирование 1.4–1.5 мм в раме и створке.
- 5–6 камер для жилого дома.
- Стеклопакет 40–48 мм.
- Надёжная фурнитура (антисрыв, микропроветривание).
- Устойчивость ламината к ультрафиолету.
- Соответствие проекту.

## Контроль
- Проверить армирование по каталогу.
- Проверить стеклопакеты по спецификации.
- Сверить цвет с реальным образцом.
- Проверить нагрузку на створки.

## Типичные ошибки
❌ Профиль класса C → деформация через год.  
❌ Нет армирования → провисание створок.  
❌ Тонкий стеклопакет → промерзание и шум.  
❌ Ошибка в цвете → переделка всего комплекта.

## Быстрый чек-лист
✅ Профиль класса A  
✅ Армирование соответствует  
✅ Стеклопакет подходит по теплотехнике  
✅ Фурнитура надёжная
