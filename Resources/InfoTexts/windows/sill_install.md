# Установка подоконника

## Что проверяем
- Подоконник установлен с уклоном в помещение 2–3 мм.
- Под ним есть жёсткая опора по всей длине.
- Пена/клей нанесены равномерно, без пустот.
- Места примыкания к рамe и откосам герметичны.
- Торцы закрыты заглушками.
- Подоконник не «играет» при нагрузке.

## Контроль
- Проверить уклон уровнем.
- Надавить рукой по всей длине — не должно быть прогиба.
- Осмотреть линию примыкания к окну.
- Проверить отсутствие щелей в углах.

## Типичные ошибки
❌ Нет опоры → подоконник прогибается.  
❌ Нулевой или обратный уклон → скопление влаги.  
❌ Пена нанесена точечно → пустоты, гулкий звук.  
❌ Щели у рамы → продувание, пыль.

## Быстрый чек-лист
✅ Уклон 2–3 мм  
✅ Жёсткая опора по всей длине  
✅ Торцы закрыты  
✅ Герметизация целая
