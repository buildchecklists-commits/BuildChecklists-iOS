# Опорный профиль под окно

## Что проверяем
- Используется оригинальный подставочный профиль.
- Профиль ровно установлен без прогибов.
- Чёткое опирание на основание по всей длине.
- Нет пустот под профилем.
- Стыковочные элементы установлены правильно.
- Наличие терморазрыва (если требуется).

## Контроль
- Проверить установку уровнем.
- Правилом проверить отсутствие прогибов.
- Проверить наличие опор под профиль.
- Сверить профиль с паспортом производителя.

## Типичные ошибки
❌ Пустоты под профилем → прогиб, рама ведёт.  
❌ Неоригинальный профиль → несовместимость с подоконником.  
❌ Уклон профиля → створки зависнут и будут подклинивать.  

## Быстрый чек-лист
✅ Профиль оригинальный  
✅ Опора непрерывная  
✅ Уровень идеальный  
✅ Стыковка выполнена правильно
