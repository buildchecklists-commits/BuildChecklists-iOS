# Монтажные зазоры окна

## Что проверяем
- Размер зазора по периметру: не слишком маленький и не чрезмерный.
- Равномерность зазора с каждой стороны рамы.
- Возможность нормального запенивания и работы лент.
- Учёт температурных расширений профиля.

## Контроль
- Измерить расстояние между рамой и проёмом по нескольким точкам.
- Проверить, хватает ли места для пены и лент.
- Убедиться, что рама не зажата «в распор» в жёсткий проём.

## Типичные ошибки
❌ Раму зажимают без зазора → деформации при расширении.  
❌ Слишком большой зазор, который сложно качественно заполнить.  
❌ Разные зазоры по сторонам → кривой узел и нестабильность.  

## Быстрый чек-лист
✅ Зазоры выдержаны и равномерны по периметру.  
✅ Есть место для пены и работы лент.  
✅ Рама не зажата, учтены температурные расширения.
