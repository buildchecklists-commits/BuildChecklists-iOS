# Траншея

## Что проверяем
- Глубина/ширина траншеи по проекту.
- Стабильность откосов, отсутствие осыпаний.
- Дно не разрыхлено, без луж.

## Контроль
- Измерения рулетка/рейка + нивелир.
- Откосы по ТБ, при необходимости — крепления.
- При появлении воды — прокачка/дренаж.

## Типичные ошибки
❌ Недобор глубины / завал стенок.  
❌ Разрыхлённое дно.  
❌ Вода и ил на дне.

## Быстрый чек-лист
✅ Размеры по проекту.  
✅ Откосы устойчивы.  
✅ Дно чистое, без воды.
