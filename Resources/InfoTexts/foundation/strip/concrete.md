# Бетон/бетонирование/уход

> Правильный класс/подвижность/морозостойкость, сплошное уплотнение и уход.

## Что проверяем
• Марка/класс бетона, П-подвижность, F-морозостойкость, W-водонепроницаемость — по проекту/ЗиФ  
• Паспорт бетона, время прибытия/температура смеси  
• Укладка непрерывно, без «холодных швов»  
• Виброуплотнение глубинным вибратором — послойно  
• Вертикали/плоскости не уводит, опалубка не «раздувается»  
• Разравнивание верха ленты — по нивелиру/правилу  
• Уход: укрытие/полив; зимой — прогрев/термоодеяло по ППР

## Контроль
• Журналы бетонирования, акты на бетон  
• Время перерывов между замесами, карта укладки  
• Температурный журнал (зима), инфракрасник/термометры

## Типичные ошибки
❌ Нет вибрации/перевибрация (расслоение)  
❌ Холодные швы; перерывы > допустимых  
❌ Не учтены зимние меры (прогрев/противоморозные)  
❌ Не выровнен верх — проблемы с кладкой/гидроизоляцией

## Быстрый чек-лист
✅ Паспорт бетона проверен, класс/П/F/W совпали  
✅ Виброуплотнение сплошное, без разрывов  
✅ Верх выровнен по уровню  
✅ Уход/прогрев организован, акт/журнал есть
