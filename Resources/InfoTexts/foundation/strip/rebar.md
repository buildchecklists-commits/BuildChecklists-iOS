# Армирование ленточного фундамента

> Каркасы/хомуты по проекту, защитный слой выдержан, стыки/анкеровка правильные.

## Что проверяем
• Диаметр/класс арматуры = проекту (сертификаты)  
• Кол-во продольных стержней в поясе и их шаг/расположение  
• Хомуты/стяжки: шаг по проекту; усиление углов/примыканий  
• Защитный слой: нижний/боковой/верхний (фиксаторы «лягушки», дистанцирующие)  
• Стыки: нахлёст/сварка — по проекту/СП; анкеровка в монолитных участках  
• Вязка проволокой — А-класс сталь, не «сопли»  
• Выпуски под стены/перемычки/ростверк — по отметкам

## Контроль
• Шаблоны/линейки на защитный слой  
• Фотоузлы: углы, Т-примыкания, закладные  
• Нахлёсты — мерной лентой (не короче проектного)  
• Чистота: без грязи/подсыпки внутри каркаса

## Типичные ошибки
❌ «Разбежались» защитные слои, каркас лежит на грунте  
❌ Нет усиления угол/Т-узел; хомуты «гуляют»  
❌ Нахлёсты короче нормы/внахлёст в одном сечении  
❌ Отсутствуют фиксаторы, каркас смещается при бетоне

## Быстрый чек-лист
✅ Диаметры/шаг хомутов/число стержней = проекту  
✅ Защитные слои выставлены и проверены  
✅ Нахлёсты/анкеровки выполнены по нормам  
✅ Фотофиксация всех узлов сделана
