# Спецификация дверных блоков

## Что проверяем
- Полный список дверей по помещениям.
- Тип двери, материал, отделка, цвет, размеры коробки и полотна.
- Направление открывания и наличие порога.
- Комплект фурнитуры для каждой позиции.
- Привязка к плану: какие двери где стоят.

## Контроль
- Сформировать таблицу/ведомость дверей (дверная карта).
- Сверить спецификацию с планировкой и фактом проёмов.
- Передать спецификацию поставщику/изготовителю дверей.

## Типичные ошибки
❌ Несоответствие спецификации фактическим проёмам.  
❌ Потерянные позиции (проёмы без двери в спецификации).  
❌ Неучтённые особенности: влажные помещения, улица, техпомещения.  

## Быстрый чек-лист
✅ Есть актуальная ведомость дверей по всем помещениям.  
✅ Спецификация согласована с заказчиком и строителями.  
✅ На основе спецификации можно сделать заказ без уточнений.
