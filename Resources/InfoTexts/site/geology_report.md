# Геологический отчёт

## Что проверяем
• Разрезы грунтов, литологическое описание, таблицы параметров  
• Рекомендации по фундаменту и типу основания  
• Сводная таблица несущих способностей грунтов

## Контроль
• Отчёт оформлен по ГОСТ 25100  
• Есть раздел с рекомендациями  
• Приложены чертежи и PDF-файл

## Типичные ошибки
❌ Нет рекомендаций по фундаменту  
❌ Не указаны несущие способности  
❌ Отсутствует подпись/печать исполнителя

## Быстрый чек-лист
✅ Разрезы и таблицы присутствуют  
✅ Есть выводы и рекомендации  
✅ PDF отчёт приложен в проект
