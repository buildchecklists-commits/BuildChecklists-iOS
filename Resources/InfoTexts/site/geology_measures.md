# Мероприятия: дренаж, подсыпка, подбетонка, геотекстиль

## Что проверяем
• Назначены мероприятия по результатам отчёта  
• Дренаж, подсыпка, подбетонка выполнены по проекту  
• Геотекстиль уложен с нахлёстом и без складок

## Контроль
• Подсыпка уплотнена, есть акты испытаний  
• Уклон и колодцы дренажа выполнены  
• Толщина подбетонки соответствует проекту

## Типичные ошибки
❌ «Сухая» подсыпка без уплотнения  
❌ Нет колодцев или уклонов  
❌ Геотекстиль без нахлёстов

## Быстрый чек-лист
✅ Мероприятия соответствуют отчёту  
✅ Есть акт уплотнения основания  
✅ Узлы и уклоны дренажа согласованы
