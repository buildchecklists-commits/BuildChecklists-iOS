# Раскладка панелей композитной черепицы

Правильная раскладка — основа эстетики и долговечности покрытия. Ошибка в первом ряду тянет за собой проблемы на всём скате.

## Что проверяем
- Монтаж начинается от карнизного свеса.
- Первая линия ровняется по отбивочному шнуру.
- Направление монтажа строго по инструкции (обычно слева направо).
- Вертикальный нахлёст панелей фиксированный — по замку.
- Панели разных упаковок перемешиваются для равномерного оттенка.
- Замки входят легко, без «натягивания» и ударов.

## Контроль
- Проверять горизонталь каждых 3 рядов.
- Слежение за рисунком покрытия — без «змейки».
- Все панели должны лежать ровно, без перекосов.
- Проверить отсутствие деформации при посадке в замок.

## Типичные ошибки
❌ Неровный первый ряд — вся плоскость уходит «волной».  
❌ Панель «дотягивают» до замка → повреждение защёлки.  
❌ Недостаточный вертикальный нахлёст → поддувания ветром.  
❌ Не перемешивают партии → пятнистость цвета.

## Быстрый чек-лист
- ✅ Первый ряд идеально ровный  
- ✅ Направление монтажа по паспорту  
- ✅ Замки входят легко  
- ✅ Нахлёсты совпадают  
- ✅ Панели перемешаны из разных упаковок
