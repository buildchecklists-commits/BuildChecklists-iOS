# Документы по полувальмовой крыше

## Что проверяем
- Акты скрытых работ.
- Паспорта на покрытие, плёнки, утеплитель, крепёж.
- Гарантии подрядчика.
- Исполнительные схемы (если предусмотрены).

## Контроль
- Сверка актов по всем слоям.
- Проверка подписей и дат.
- Архивация в электронном виде.

## Типичные ошибки
❌ Нет актов на скрытые работы — споры при приёмке дома.  

## Быстрый чек-лист
✅ Документы собраны и подписаны.
