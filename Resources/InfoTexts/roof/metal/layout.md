# Раскладка и монтаж листов металлочерепицы

## Что проверяем
- Схема раскладки листов согласована (откуда начинаем, куда идём по скату).
- Первый ряд от карниза выставлен по шнуру, нет «зубов» и разбега.
- Совпадение модулей/волн по горизонтали и вертикали, нет уводов.
- Перехлёст листов по инструкции (обычно 1 волна по горизонтали, 1 модуль по вертикали).
- Подрезки у стен, труб, фронтонов выполнены ровно, без рваных кромок.
- Карнизная линия прямая, свес по лобовой доске одинаковый по всей длине.

## Контроль
- Проверить карнизную планку и первый ряд листов по шнуру/лазеру.
- Измерить свес металлочерепицы относительно лобовой доски в нескольких точках.
- Осмотреть зоны стыковки листов — волна к волне, нет смещения по шагу профиля.
- Проверить, что подрезки выполнены ножницами по металлу/спец-инструментом, а не болгаркой (нет подпалацинкования).
- Убедиться, что листы не «заламаны» по профилю и не погнуты при поднятии/переноске.

## Типичные ошибки
❌ Первый ряд положили «на глаз», в результате весь скат «пляшет».  
❌ Стопки листов тащили по покрытию — поцарапали полиэстер/пурал.  
❌ Подрезали болгаркой — на кромке ржавчина через пару сезонов.  
❌ Нет нормальной схемы раскладки — лишние стыки, сильно режут листы, перерасход материала.  

## Быстрый чек-лист
✅ Первый ряд выровнен по шнуру, свес одинаковый.  
✅ Листы совпадают по волнам и модулям, стыки ровные.  
✅ Подрезки аккуратные, без подпала и рваного металла.  
✅ Листы не поцарапаны и не погнуты.
