# Вентиляция — проект и расчёт

## Что проверяем
- Есть расчёт необходимой кратности воздухообмена.
- Выбрана система: естественная / механическая / приточно-вытяжная с рекуперацией.
- Разделение зон: кухня, санузлы, жилые помещения.
- Приток/вытяжка сбалансированы.

## Контроль
- Проверить проект или схему.
- Убедиться, что выбранные установки подходят по производительности.

## Типичные ошибки
❌ «Открывать окна» — не вентиляция.  
❌ Только вытяжка без притока → подсосы через щели.  
❌ Неправильная производительность установки.

## Быстрый чек-лист
✅ Проект есть.  
✅ Выбрано правильное оборудование.
