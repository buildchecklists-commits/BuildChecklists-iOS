# Армирование стяжки по стальным балкам

## Что проверяем
- Тип сетки (диаметр, ячейка).
- Укладку сетки на фиксаторы — не на профнастил.
- Перехлёст 1–2 клетки.
- Наличие демпферных лент по периметру.
- Правильное расположение маяков.

## Контроль
- Проверка размеров сетки и нахлёстов.
- Контроль высоты защитного слоя.
- Осмотр фиксаторов.
- Проверка периметральных лент.

## Типичные ошибки
❌ Сетка лежит прямо на настиле.  
❌ Нет демпфера — стяжка трескается по периметру.  
❌ Нет нахлёстов сетки.  

## Быстрый чек-лист
✅ Сетка на фиксаторах, маяки установлены.
